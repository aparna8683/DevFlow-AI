# DevFlow AI

An AI-powered collaborative software engineering team.

## Goal
Build a multi-agent system that helps developers investigate, reproduce,
and resolve software bugs with human approval.

## Planned Agents
- Triage Agent: Classifies incoming bug reports.
- Debugging Agent: Investigates issues and reproduces bugs.
- Review Agent: Reviews proposed fixes and tests.
- Human Developer: Approves changes before implementation or merging.

## Planned Technology
- Switch
- Mattermost
- OpenCode
- Ollama
- Docker
- GitHub
